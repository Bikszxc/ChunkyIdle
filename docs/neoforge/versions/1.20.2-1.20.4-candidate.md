# NeoForge 1.20.2–1.20.4 shared-jar candidate

The shared candidate is built from the NeoForge 1.20.2 project. Its metadata declares Minecraft versions `[1.20.2,1.20.5)`, covering 1.20.2, 1.20.3, and 1.20.4. Pair it with Chunky 1.3.146.

## Build

From the repository root, run:

```powershell
.\gradlew.bat :neoforge:1.20.2:candidateJar -PcandidateNeoForgeRange=1.20.2-1.20.4
```

The artifact is written to:

```text
build/candidates/neoforge/1.20.2-1.20.4/chunkyidle-neoforge-0.1.1-mc1.20.2.jar
```
