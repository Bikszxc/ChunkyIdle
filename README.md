# Chunky Idle

Chunky Idle is a server-side companion for [Chunky](https://modrinth.com/mod/chunky). It pauses active Chunky generation when players join and resumes eligible tasks after the server has been empty for a while. Players do not need to install it on their clients.

## Features

- Pauses running Chunky tasks when a player joins.
- Resumes tasks after the server has been empty for a configurable time.
- Can recover eligible saved tasks after a graceful server restart.
- Preserves Chunky’s saved progress and never starts a generation task itself.
